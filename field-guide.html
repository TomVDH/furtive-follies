01 · Context management

A vault is your project's memory.

Work spans days. The why behind a decision, what you tried last week, where you left off — it lives in your head or scrolls out of a chat, and then it's gone. A vault holds it instead: a plain folder of markdown files, in a consistent shape. It's an Obsidian vault, but you never open Obsidian — the files are just text.

What lives in it

Sessions
What happened each day you worked
Decisions
The choices you made, and why
Handoff
Where things stand, for next time
Board
Your tasks, on a kanban

02 · The plugin

adjudant keeps it current. You just work.

It's a Claude Code plugin that writes to the vault for you. Most of it is invisible — some things happen on their own, and a handful of commands are there when you want them.

Happens on its own
· A session note, per day
· The handoff, kept current
· The board, reseeded from tasks
· Every write, checked against a shape
You run it
· connect — once per project
· sitrep — when you come back
· check — a health look
· tidy — gentle cleanup

The seven verbs

connectLink a project to its vault
syncPush current state to the vault
checkHealth reportro
sitrep“Where was I?” after a breakro
tidySafe surface cleanup, previews first
dreamAdvisory reviewro
boardDrag-and-drop kanban
On dream, and on cost

dream reads your notes and hands you a report — what's stale, what contradicts, what's orphaned — then stops. It changes nothing on its own; you decide. And the whole plugin is built to be light: heavy reads estimate their cost and ask before spending.

03 · Setup

Three steps, then you're running.

1

Get access

The repo is private. Sign in to GitHub once per machine so Claude Code can read it.

Terminal
$gh auth login
2

Install the plugin

Two lines inside Claude Code. If either can't reach the repo, it's the access step above.

In Claude Code
/plugin marketplace add TomVDH/furtive-follies
/plugin install adjudant
3

Connect your project

Once per project. It shows the vault locations on your machine, recommends one, and creates the vault for you.

In Claude Code
/adjudant connect

Where your vault should live

Cloud-sync folder · recommended
iCloud, OneDrive, Google Drive, Dropbox. Your notes follow you across machines.
Local folder
~/Documents. Fine if you only ever work on one machine.
→

That's it. The record-keeping runs from here. Come back with /adjudant sitrep after a break.

04 · The suitcase

A friendlier terminal, optional.

The bundle ships a small kit of guarded command-line tools — the suitcase. It makes the terminal nicer without changing how anything works, and it's entirely optional. Dry-run first; anything already installed is skipped.

Terminal · from the repo
$bash onboarding/onboard.sh --check
$bash onboarding/onboard.sh

What it installs

zoxide
Jump to folders: z name
eza · bat
Prettier listings and file reading
ripgrep · fd
Fast search and find
git-delta
Readable git diffs
glow
Read markdown in the terminal
tldr
Plain, example-first help
trash
A safer rm
sl · cbonsai
A little fun

Recommended terminal setup

Required
Zsh · zsh.org
The shell the shortcuts assume. It's the macOS default since Catalina — make it active if it isn't.
chsh -s /bin/zsh
Recommended
iTerm2 · iterm2.com
A nicer terminal than the built-in one. Repo: gnachman/iTerm2
brew install --cask iterm2
Recommended
Powerlevel10k · romkatv/powerlevel10k
A fast, informative zsh prompt. Install, add it to ~/.zshrc, then run p10k configure. Install guide →
brew install powerlevel10k

Not on a Mac? Install the tools with your own package manager, then source onboarding/casual-qol.zsh. The shortcuts are guarded either way.

05 · If something looks off

Two fixes cover most of it.

Vault not found
Re-run /adjudant connect — it re-links the project.
A write got blocked
The message names the field to fix. Adjust it, write again.
No board yet
It's born on your first task note. No tasks, no board.
